# Convexity Screener · 凸性错杀选股器

一个在本机运行的美股研究工具：每周从 NYSE + Nasdaq 约 5000 家运营公司里，找出**基本面硬、价格被外部因素压住、下行有限上行大**的候选公司，每家附一张「为什么选它 / 卡在哪」的卡片，再由使用者自己判断是不是真的错杀。

- **只用免费数据**：SEC 财报、Yahoo 行情、Google 新闻、Wikidata，不需要任何付费数据源或 API key。
- **规则透明**：四层漏斗的每条阈值都写在配置里，每家公司都能看到具体卡在哪一条、差多少。
- **数据留在本机**：Go 后端 + SQLite + React 前端，全部跑在 `127.0.0.1`。
- **可选的 AI 辅助**：调用本机已登录的 AI 命令行（Codex、Claude Code、Gemini / Antigravity、Grok）做诊断和 X 舆情，也可以用自己写的 Skills 只基于事实数据分析。

> **免责声明**：本项目仅用于个人学习和研究，不是交易系统，不构成任何投资建议。筛选结果和 AI 输出都可能出错，数据来源也可能不完整或有延迟，请自行核实并承担投资决策的后果。

## 快速开始

需要 Go ≥ 1.27、Node ≥ 20。AI 功能是可选的，需要另外安装并登录对应的命令行工具（见下文「AI 诊断」）。

```bash
git clone https://github.com/yunjiansong/screener.git && cd screener

# SEC 要求请求头里带真实联系方式，先写进本地配置（不入库）
echo '{"secUserAgent": "StockScreener your-email@example.com"}' > backend/config.json

make build      # 编译前端和后端
make run        # 跑一次完整筛选（首次要下载约 1.4GB 的 SEC 数据包，之后一周内复用）
make serve      # 打开 http://127.0.0.1:8090
make show T=JD  # 在终端查看某家公司卡在哪一层
./backend/bin/screener alerts   # 立即扫描一次观察列表并发提醒邮件
make test
```

网页上的「重新筛选」按钮等同于 `make run`。前端开发时用 `make dev`（端口 5180，`/api` 代理到 8090）。

## 筛选逻辑：四层漏斗

所有阈值在 `backend/internal/config/config.go` 的 `Default()` 里。也可以在 `backend/config.json` 中覆盖部分字段（只写需要改的那些）。

| 层 | 想回答的问题 | 默认规则 |
|---|---|---|
| **L1 质量** | 生意本身硬不硬？ | ≥5 年年报；最近 5 年里至少 4 年 FCF 为正；FCF 利润率中位数 ≥5%；营业利润率中位数 ≥8%；收入 5 年复合增速 ≥−3%；净债务不超过 3 年平均 FCF 的 4 倍；质量分 ≥50 |
| **L2 价格错位** | 价格是不是被压住了，而基本面没坏？ | 不是金融或地产；市值 ≥$1B；较 5 年高点回撤 ≤−30%；P/FCF 处在自身历史的 30% 分位以下；正常化 FCF 收益率 ≥4%；近 3 年 FCF 均值 ≥ 此前的 80%；最新一年 FCF ≥ 3 年均值的 50%；最新收入 ≥ 近 3 年最高值的 90% |
| **L3 凸性** | 赔率是否不对称？ | 上行：估值倍数回到历史中位数（最高按 30 倍算），涨幅 ≥40%。下行：倍数停在"当前"和"历史 P10"中较低的那个，同时 FCF 再跌 20%，跌幅不超过 60%。凸性 = 上行 ÷ 下行，要求 ≥2 倍 |
| **L4 你的判断** | 是外部原因，还是公司自己变坏了？ | 系统只给线索：中概股/外国公司标记、同行业是否集体下跌、收入或利润率下滑、股本稀释、最新年 FCF 骤降、价格与 FCF 走势背离。你给出判断（外部错杀 / 内部恶化 / 说不清 / 观察 / 排除），写下理由，判断会跨批次保留 |

**护城河怎么量化？** 护城河本身看不见，但它会留下"脚印"：ROIC 高且稳定、毛利率高且稳定。质量分（0–100）的构成：ROIC 30 分、毛利率水平 20 分、利润率稳定性 15 分、FCF 稳定性 15 分、增长 10 分、资产负债表 10 分。

**关键口径**：
- FCF = 经营现金流 − 购建固定资产的现金支出。正常化 FCF = 最近 3 个财年的 FCF 均值，换算成美元。
- 某一年的财报只在财年结束约 100 天后才算"已知"，计算历史估值时不会用到当时还没发布的数据。
- 有息负债不含租赁负债。现金包含短期投资。
- 某些年份没有标注资本开支时，用该公司自己历史上"资本开支/收入"的中位数来估算，界面上标"估"。
- 营业利润缺失时，用税前利润代替（常见于药企和外国公司）。

## 页面

- **首页（工作台）**：回答「今天该先处理哪家」。
  - 顶栏：标题、页面导航、**AI 诊断胶囊**（批量进度；点开看每家的步骤，或发起新一批）、上次筛选时间、重新筛选。
  - **今日待办**四张卡（点击筛选下方表格，再点取消；卡片筛选跨所有层级）：
    - **证伪条件触发**：你在详情页写的量化证伪条件（如「毛利率 < 55%」）被最新财报或股价击中。
    - **到期复查**：复查日 ≤ 今天，并对比判断时冻结的股价。
    - **新进候选**：对比最近一次候选名单不同的历史批次，列出新进 / 移出。
    - **14 天内财报**：财报日期来自 Nasdaq 公开接口（Zacks 预估或公司确认，✓ 表示已确认），取不到时按 SEC 过去的业绩公告（8-K 2.02）推算。
  - 漏斗压成一行分段控件（悬停看留存率和层级定义），与搜索、判断筛选、判断进度同一行；下方是**行业分布**按钮（同行业 ≥ 3 家时标蓝，提示可能是行业性下跌）。
  - 表格列：勾选框 / 公司（「新进」「冲突」标签）/ 市值 / 较 5 年高点 / FCF 收益率 / 估值分位 / 凸性（第二行是上行；下行不是 −20% 时写出来）/ 质量 / 系统线索 / AI 结论（偏错杀 / 偏恶化 / 看不清，副行是模型一致程度或当前步骤）/ 下次财报（14 天内黄底）/ 我的判断（证伪触发红、复查到期黄）。
  - 「冲突」：系统把它筛为候选，但 AI 倾向「恶化」；或 AI 看不清而系统没有任何内部预警；或各模型结论不一致。
  - 综合分 = 质量分 × 0.5 + 5 × min(凸性, 10)，悬停「公司」表头可见。
  - 勾选多行后底部浮出操作条：加入观察 / 排除 / 重新 AI 诊断（ChatGPT + Gemini 并综合）/ 取消，`Esc` 取消选择。
- **详情页**：先看结论和冲突，再按需展开证据。`J` / `K` 切换上下一家，`1`–`5` 选结论，`⌘/Ctrl + Enter` 保存并看下一家，`Esc` 返回。
  - 页头写明报告币种；外币公司注明汇率：今天的估值（市值对比 FCF、现金、负债、每股内在价值、反向 DCF）按筛选时 Yahoo 的最新汇率换算；历史 P/FCF 序列按各期当时的汇率；年度财务保留原币。近几年资本开支未在 XBRL 单列时，页头下有「估」提示条，依赖 FCF 的数字（P/FCF、反向 DCF、内在价值、上行 / 下行、L3）都带「估」标记。
  - 顶部指标条（3 × 2）：现价与距 5 年高点、P/FCF 与历史分位、**反向 DCF · 按 EV**（价格隐含的 FCF 年增速，用市值 + 有息负债 − 现金反推，并列按市值算的结果和过去 5 年实际）、**内在价值 / 股 · 3 情景**（悲观：DCF 起始增长取最近一年实际收入增速，不高于 0；基准：与安全边际同一套假设的 DCF；乐观：回到目标倍数）、上行 / 下行、市值与现金 / 负债（USD）。L1 有趋势预警时顶部标签显示「! L1 质量 · 趋势预警」。
  - 左栏依次是：
    1. **判断要点**：信号冲突逐条写明数字（如「安全边际显示低于内在价值 62%，AI 结论为看不清，差异来自增长假设」「L1 按 5 年中位通过，但 TTM 毛利率 63.0% → 56.3%」），下面四栏：最可能原因（12 项排查里排前 3 的，「看全部 12 项排查」展开下方原因卡）/ 支持错杀 / 反对错杀 / 待核实，每栏最多 3 条，每条标注来源。X 上的传闻只进「待核实」。
    2. 股价图与 P/FCF 历史。
    3. 筛选证据（折叠时只显示趋势预警和未通过项）。L1 的趋势规则对比最近 12 个月和 5 年历史，只预警不淘汰，同时在系统线索加「内部恶化」：
       - 毛利率较 5 年中位跌 > 3pp；
       - 最近一年收入增速低于 5 年年均的一半（年均 ≥ 5% 时才判）；
       - 营业利润率较 5 年中位跌 > 3pp；
       - FCF 利润率较 5 年中位跌 > 5pp。
    4. **同行业对比**：本公司 / 行业中位 / 行业市值最大公司三行，列为毛利率、营业利润率、FCF 利润率、收入增速、ROIC、FCF 收益率、P/FCF、较 5 年高点；本公司偏离中位最大的两项标黄（偏离 ≥ 25% 才标），悬停看高 / 低多少。只有通过 L1 的公司有行情，所以同行是「同行业里质量也过关的公司」，不足 3 家时放宽到同板块。
    5. 年度财务（原币；TTM + 近 6 个财年，可展开全部；TTM 利润率低于 5 年中位标黄）。
    6. **折叠区**：每张卡片默认折叠，只显示一行摘要和标签，展开状态会记住：
       - 原因排查：12 项，每项写明依据的数据和方法，按「较可能 / 有迹象 / 不像 / 看不出」排序。分三类：
         - 陷阱型（便宜有道理）：基本面恶化（利润率趋势、FCF 保持、Piotroski F）、周期顶部利润、财务风险（Altman Z、净债务 / EBITDA、利息保障）、盈利质量（Sloan 应计、FCF / 净利润、股权激励）、股东稀释、结构性颠覆（定性为主）；
         - 中性：增长放缓导致估值下修（反向 DCF 隐含增速 vs 历史增速）、估值从高位回落（跌幅拆成倍数变化 × FCF 变化）、公司特有问题（比同行多跌多少）；
         - 可修复：行业整体下跌（同行中位跌幅）、一次性 / 外部事件（新闻关键词、中概股折价）、被市场忽视（关注度、市值）。
         每次 AI 诊断也会逐项给出判断和一句理由。
       - 近期新闻（摘要显示涨跌最大的一条）。
       - 市场情绪：成交量、维基浏览量和 X 舆情，多空观点和传闻；底部是 Grok 的调用细节（模型、触发方式、用时、轮数、token、费用、可用工具和命令行）。
       - 专业指标（F 分数 / Z 分数 / FCF ÷ 净利润 / ROIC；现金多到让 ROIC 分母为负时改为不扣现金）。
       - **安全边际明细**：每股内在价值 × (1 − 安全边际，默认 30%)。内在价值取勾选方法的中位数：
         - 两阶段 DCF（第 1 年按起始增长率，N 年内线性降到永续增速，加净现金；起始增长率默认取「过去 5 年 FCF 增速、最近一年收入增速、8%」中最低的，不低于 0，输入框旁显示现价隐含的增速）；
         - 无增长价值 EPV（FCF ÷ 折现率 + 净现金，保守底线）；
         - 历史倍数回归（FCF × 系统目标倍数）；
         - 格雷厄姆公式 EPS × (8.5 + 2g) × 4.4 ÷ AAA 债收益率；
         - 格雷厄姆数 √(22.5 × EPS × 每股净资产)（轻资产公司会低估，默认不计入）；
         - 各 AI 模型自己估的悲观 / 基准 / 乐观区间；
         - 我的估计（自己填数字和依据）。
         「调整假设」里可以改安全边际、折现率、增长率、年数、永续增长、AAA 收益率、目标倍数、FCF 起点，保存为本公司假设或设为所有公司的默认；顶部的 3 情景用同一套已保存的假设。每股数字按「市值 ÷ 股价」的流通股折算，ADS 和外币已处理。
       - **Skills 分析**：用自己写的 skill（只给事实数据）分析当前股票，结果按公司保存，见下文「Skills」。
       - **AI 诊断**：结论、模型一致度、「留给你判断的问题」和「行动前要核实」；带明确阈值的条目可以一键「采纳为证伪条件」。各模型详细分析与诊断记录折叠。
       - 公司概况。
  - 右栏 **L4 判断**：
    - 系统线索（同类合并在一个标签下）、结论，以及三个问题：市场担心什么 / 为什么是暂时的 / 什么事实说明你错了。
    - 已采纳的量化证伪条件以标签显示，也可以手动添加。
    - 下次复查日有「财报后」快捷按钮。
    - 勾选「加入观察列表」后，复查日和证伪触发时都会发邮件。
    - 保存时冻结当时的股价、P/FCF、TTM 利润率、AI 结论和证伪条件，复查时对比。面板高度随位置自适应，保存按钮始终可见。
  - 专业指标的完整清单：
    - 盈利质量。
    - 资本回报。
    - 偿债。
    - 股东回报与稀释。
    - 营运效率。
    - 每项都有近 6 个财年 + 最新 TTM 走势。

公司概况和新闻在打开详情页时现取，首次约 10–30 秒，之后走缓存（年报 90 天、维基 30 天、新闻 3 小时）。终端里可以用 `./bin/screener profile LULU` 查看同样的内容。

## 季报数据（TTM）

年报一年才出一份，所以只看年报，到年底数据会滞后快一年。现在对提交 10-Q 的公司（约 3/4）使用**滚动 12 个月（TTM）**：

> TTM = 最新年报 + 今年至今的季报累计 − 去年同期累计

同样的算法往前推 1 年、2 年，得到三个互不重叠、都截至最新季度月份的 12 个月。"当前"的指标都用这三段：正常化 FCF、FCF 收益率、估值倍数和凸性、"最新年 FCF ≥ 均值 50%"、收入保持、净债务。5 年质量检查（FCF 为正年数、利润率中位数、收入增速）和估值历史仍然用财年数据。

外国公司（20-F / 40-F）不提交 10-Q：最新年报超过 100 天时，用 Yahoo 最近 4 个季度相加得到最新的 TTM（只用报告币种、4 个季度需连续、收入在年报的 0.5–2 倍之间、必须有季度经营现金流），财务表该行标「Yahoo」。取不到时仍用年报（如 TCOM，Yahoo 没有它的季度现金流）。

## 观察列表与邮件提醒

- **加入**：在详情页把结论设为「加入观察」会自动加入；也可以直接点「加入观察列表」。
- **扫描**：`make serve` 运行时，按「提醒设置」里的间隔（默认 6 小时）自动扫描；也可以点「立即扫描」，或运行 `./backend/bin/screener alerts`。每次扫描取 Yahoo 最新日线，按最近一次全市场筛选的正常化 FCF 重新计算估值。
- **规则**：价格 ≤ / ≥ 目标价、单日跌幅、较 5 年高点回撤、FCF 收益率、P/FCF、估值修复上行、新闻发布后首个交易日的大幅涨跌、跌出加入时所在的筛选层、出新财报、到了你写的下次复查日期。默认阈值在「提醒设置」里改，每家公司可以单独覆盖（填 0 关闭某条默认规则）。
- **只提醒一次**：条件"刚满足"时发一封；一直满足不重复发；条件消失后再次满足才会再发。一次扫描触发的所有提醒合成一封邮件。
- **邮件**：在「提醒设置」填 SMTP。Gmail 用 `smtp.gmail.com`、端口 587、账号填邮箱、密码填「应用专用密码」（Google 账号 → 安全性 → 两步验证 → 应用专用密码）。密码可以改用环境变量 `SMTP_PASSWORD` 提供，不存进数据库。没配置 SMTP 时，邮件存到 `data/outbox/`，可以先用浏览器打开预览。

## AI 诊断与 X 舆情

不需要 API key：后端调用本机**已登录**的 AI 命令行，以非交互模式运行，用的是你自己的订阅额度。

| 引擎 | 命令 | 账号 |
|---|---|---|
| Codex（默认） | `codex exec` | ChatGPT 订阅（`codex login`） |
| Claude Code | `claude -p` | Claude 订阅；**额度有限，只在详情页手动选择时使用** |
| Antigravity | `agy -p` | Google 账号（Gemini 等模型） |
| Grok | `grok -p` | grok.com / X 账号（`grok login`）；**X 舆情专用** |

- **AI 诊断**（详情页卡片）：把筛选证据、财务（含 TTM）、专业指标、每股估值输入、同行对比（同行业通过 L1 的公司中位数和市值前 3 名）、新闻、关注度、你的判断、上次诊断、近 10 天的 X 舆情打包成提示词，要求按固定 JSON 结构输出：结论（错杀 / 定价合理 / 价值陷阱 / 看不清）、信心 1–5、市场在担心什么、是否暂时、看多看空、证伪条件、接下来盯什么、数据疑点、每股内在价值区间、12 项低价原因的逐项判断。可在页面上临时换引擎。
- **触发方式**：手动；观察列表定期（默认每 7 天）；提醒触发后（该公司的提醒一触发就诊断）。每次结果都存进 `ai_diagnosis` 表，失败也记录。
- **汇总历次**：至少 2 次成功诊断后，让 AI 对比历次结论：哪些一致、哪些变了、变化是否基于新事实、还剩什么要你判断。可设为每次新诊断后自动刷新。
- **X 舆情**：Grok 用 X 搜索（`x_keyword_search` / `x_semantic_search` / `x_thread_fetch`）调查近 30 天讨论：情绪分、热度、主要叙事、多空论点、代表性帖子、待核实传闻。每条帖子的链接都会用 X 帖子 ID 里的时间戳核对日期，对不上的标为「链接可疑」（AI 偶尔会编链接）。
- **安全**：诊断在 `data/ai/` 下的空临时目录里运行。Codex 只读沙箱，Claude 无工具，agy 沙箱模式。Grok 用拒绝列表移除所有本机工具（终端、读写文件等），并且不自动批准任何操作；注意 Grok 的 `--tools` 白名单遇到未知名字会退回「全部工具可用」，所以这里不用它。
- **额度**：设置页可设每天自动运行上限（默认 20 次）。一次诊断约 1 分钟，X 舆情约 4–5 分钟。
- **Claude 仅手动**：定期诊断、提醒触发、自动汇总和批量任务都不会用 Claude；默认引擎即使设成 Claude，自动任务也会改用 Codex，批量请求里带 Claude 会被拒绝。
- **多模型与批量**：每个引擎有独立队列，不同模型可以同时运行，同一模型一次只跑一个。列表页「AI 批量诊断」会对按评分排前 N 的候选逐家处理：先用 Grok 搜 X 舆情，再让选中的模型并行诊断，最后用默认引擎「综合各模型」，比较共识与分歧。批量任务不计入每日自动上限。
- **展示位置**：
  - 列表「线索」列：`AI·结论` 标签，取综合结论，没有综合时取多数；小圆点每个代表一个模型的结论，悬停可看各模型的一句话结论。
  - 详情页：X 舆情在「市场情绪」折叠卡里；AI 诊断在折叠区的「AI 诊断」卡里，按「① 综合判断 → ② 各模型结论对比 → ③ 分模型详细分析（标签切换）→ 全部记录（折叠）」排列。
  - 观察列表：「AI 最近诊断」列。
- **复制提示词**：不调用本机 AI，把同样的数据复制到剪贴板，可粘贴到任何聊天网页。
- 设置在「提醒设置」页的「AI 诊断」卡片；观察列表多了「AI 最近诊断」列。

## Skills：自己的分析方法

内置的 AI 诊断带着「凸性错杀」框架和固定的输出结构。Skills 用你自己写的指令替换它：

- **管理**（顶部导航「Skills」）：新建、编辑、删除。每个 skill 有名称、说明、分析指令、默认模型。有「护城河与资本配置」「空头视角」「市场预期拆解」三个模板可以起步。删除 skill 不会删掉已经跑出的结果。
- **只给事实**：提示词 = 你的指令 + 这家公司的事实数据，包括公司与业务构成、近 6 年财务和 TTM、股价与估值倍数历史、估值统计（P/FCF、分位、中位、FCF 收益率、保持率）、专业指标数值、反向 DCF、每股估值输入、同行对比、新闻、关注度、最新行情。不包含内置诊断的框架和要求、L1–L3 的通过 / 未通过、系统线索、目标倍数与上行 / 下行 / 凸性、指标的「好 / 临界 / 差」评级、同行对比的用途说明。
- **附带材料**（默认关闭，每个 skill 单独勾选）：系统筛选结论、我的判断、上次 AI 诊断、X 舆情。勾选后提示词里会注明「这些是观点而不是事实」。
- **运行**：在公司详情页折叠区的「Skills 分析」里选 skill 和模型后运行，走和 AI 诊断相同的队列（每个模型同时只跑一个任务）。因为是手动触发，Claude 也可以用。
- **复制**：「复制提示词」复制 skill 指令 + 事实数据，「只复制事实数据」只复制数据，都可以粘贴到任意聊天。Skills 页面也可以输入股票代码预览完整提示词。
- **结果**：以 Markdown 保存在 `skill_runs` 表，连同当时的指令、附带材料、模型、股价、用时；之后改了 skill 也不影响历史结果。结果可以复制或删除。

## 数据来源（全部免费）

| 数据 | 来源 | 说明 |
|---|---|---|
| 上市公司列表 | SEC `company_tickers_exchange.json` | 只保留 NYSE 和 Nasdaq，按名称剔除 ETF、信托、SPAC |
| 年度财务 | SEC `companyfacts.zip` 全量包（约 1.4GB，每日更新） | US-GAAP 和 IFRS 都支持，任何报告币种 |
| 月度股价、市值、行业、汇率 | Yahoo Finance 公开 JSON 接口 | **非官方接口**：没有服务保证，可能限流或变更；用于个人研究 |
| 业务介绍、收入构成 | SEC 最新 10-K / 20-F 正文与 XBRL | 40-F（加拿大公司）的业务介绍在附件里，暂不解析 |
| 中文简介 | Wikidata（按 CIK 或代码查找）→ 中文维基百科 | 只有知名公司有中文条目 |
| 中文公司名 | Wikidata，一次性导入 `company_zh` 表：`python3 scripts/zh_names.py data/screener.db` | 先按 CIK 匹配，再按 NYSE / Nasdaq 代码匹配（英文名须一致，防止代码被别的公司重用）；脚本里有少量手动补充和排除。新公司不会自动补，需要时重跑脚本 |
| 新闻 | Google 新闻 RSS | 仅限个人非商业使用 |
| 翻译 | translate.googleapis.com | **非官方接口**；翻译失败时显示英文原文 |

SEC 要求请求头里带联系方式。默认值是占位符，请在 `backend/config.json`（不入库）里写 `{"secUserAgent": "StockScreener 你的邮箱"}`，或用环境变量 `SEC_USER_AGENT` 覆盖。所有下载都缓存在 `data/cache/`：SEC 数据包 7 天，价格 20 小时，市值 7 天，行业 30 天。

## 已知局限

- **外国公司只有年报**：季度变化要等下一份 20-F 才会反映，最近的情况看新闻。
- **历史市值的近似**：用"当前市值 × 股价变化"倒推历史市值，忽略了回购和稀释。对持续回购的公司，历史倍数会被低估，结论偏保守。
- **ADR**：市值直接取 Yahoo 的美元市值，不需要知道 ADS 换股比例。
- **金融、保险、REIT**：通用的 FCF 指标不适用，在 L2 直接排除。
- **价值陷阱**：系统看到的全是历史数据。竞争格局变化、"外部因素其实是永久的"，这些只能靠 L4 的人工判断。

## 一次运行的示例（2026-11-07）

漏斗：上市运营公司 5232 → 有财报数据 4941 → L1 质量 695 → L2 价格错位 75 → L3 凸性 50。首次运行约 7 分钟，之后走缓存约 10 秒。

5 个关注样本：
- **PDD、LULU、NVO**：四层全部通过。
- **JD**：卡在 L1。营业利润率中位数只有 1.9%，属于低毛利零售模式；同时 L2 显示 2025 年 FCF 只有近 3 年均值的 28%。
- **PFE**：卡在 L1。2021–2022 年的新冠高基数让 5 年收入复合增速变成 −6.3%。

开发过程中发现并修复的数据问题：油气公司的勘探开发支出、租赁公司的车队采购没有算进资本开支，导致 FCF 被高估（例如 NOG 的 FCF 收益率被算成 56%）。
